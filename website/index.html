项目说明

设计目标

让内容专注于表达，让格式服务于阅读。

  • 清晰的文档结构
  • 灵活的样式方案
结构保留，样式随心MD  →  DOCX
文件留在本机桌面应用本地处理，不必上传文稿
Word 样式可配置页面、字体、标题与表格均可调整

为文档交付而设计

从写作格式，到交付格式

让熟悉的 Markdown 工作流，也能满足日常文档规范。

01 / 结构

保留内容层次

标题、列表、引用、表格、代码块与图片按文档结构转换，减少交付前的重复排版。

02 / 样式

匹配你的文档规范

配置纸张、页边距、中英文字体、字号、行距、标题和表格样式，保存并复用方案。

03 / 自动化

批量处理也从容

选择文档或文件夹进行批量转换，也可以通过 CLI 集成到已有脚本和工作流。

简单而清晰

三步完成，
不打断写作。

先用 Markdown 组织内容，再由 MD2DOCX 生成可以继续编辑的 DOCX 文件。需要时，再调整配置让输出符合你的文档要求。

01
选择 Markdown 文件

添加单篇文档，或一次选择一个文件夹。

02
选择转换方案

使用默认样式，或载入自己的配置。

03
生成可编辑的 DOCX

查看转换结果与诊断信息，继续在 Word 中编辑。

开始使用

让下一份文档，少一点重复劳动。
