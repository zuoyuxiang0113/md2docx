# 应用设置

正式应用设置存放在 Electron `userData/app-settings.json`，默认值来自 `desktop/src/app-defaults.json`。每次启动都从正式设置重新生成 `userData/workspace/app-settings.editing.json`；运行中的常规设置修改只写该工作副本，离开“常规”页面时选择保存、放弃或取消。保存时原子替换正式设置，放弃时用正式设置重新覆盖工作副本；上次异常退出遗留的草稿不会自动恢复。运行环境和关于是只读页面，日志选项即时保存。这些选项不写入文档样式配置。

## 常规

- 界面语言：中文、English。
- 启动任务：恢复上次文件列表及输出目录，或每次清空；清空时仍可使用默认输出目录。
- 外观、界面密度、启动最大化、关闭确认。
- 默认启动窗口大小：小（900×620）、中（1000×700，默认）、大（1200×820）。启动最大化开启时优先最大化。
- 服务端口：默认 5173，允许 1024–65535。开发启动器在下次 `npm run dev` 时读取该值；也可以用 `MD2DOCX_PORT` 临时覆盖。发布版直接读取本地构建文件，不依赖此端口。
- 默认输出目录：用户“文档”目录下的 `MD2DOCX` 文件夹。应用启动时确保目录存在；用户可在常规设置中改为其他目录。发行包目录不存放用户输出。
- 主题色：默认及松绿、湖蓝、紫罗兰、琥珀、玫瑰、石墨六个预设，自定义区域提供二维色盘、色相、HEX 和 RGB。主题色保存为 `general.accentColor`（六位十六进制，默认 null），同时影响全局背景、侧栏、卡片、控件、选中项和边框；深浅模式控制亮度，主题色控制色调。原生窗口按钮背景也同步。不改变 DOCX 内容颜色，文档样式预览保留中性纸张背景。
- 文件添加：允许拖放文件与文件夹、包含子文件夹。文件夹扫描跳过符号链接，仅接受 .md/.markdown。
- 快捷键启用：Ctrl+O 添加文件、Ctrl+S 保存当前上下文、Ctrl+Enter 转换。常规页保存常规设置，文档、结果和样式编辑页保存当前配置；只读设置二级页不执行保存。
- 恢复默认样式前确认。
- 配置备份在后台自动完成，不占用常规设置界面。保存或替换配置前保留原版本，损坏配置扫描时保留原件副本；备份存放在 `profile-backups`，相同内容不重复保存。每个配置最多保留 10 个正常备份和 3 个损坏副本。

任务状态单独存放在 `workspace/task-state.json`；样式编辑不再重置任务文件列表和输出目录。

## 转换

转换相关选项直接位于常规页面中的分组，不再提供独立“转换”设置入口。

- 转换完成后：不操作、打开成功 DOCX、打开输出目录。只有实际成功文件才触发；批量打开 DOCX 会打开所有成功结果。
- 本地图片缺失：继续并警告、停止当前文件转换。停止策略始终执行缺失图片检查，即使普通预检关闭；后续是否继续批量由批量错误策略决定。
- 保留既有输出冲突策略、批量错误策略、预检和默认输出目录。

## 日志

- 日志显示最近 200、500 或 1000 条，切换后重新读取并继续按任务/级别筛选。
- 日志默认保留 7 天、每目录 100 MB 总量管理，其他策略见 logging.md。

文件对话框、原生路径拖放、备份和真实转换仅在 Electron 桌面端提供。浏览器预览不具有原生文件系统权限。
