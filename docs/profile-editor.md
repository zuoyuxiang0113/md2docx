# 配置与样式页面

配置页采用两级流程。点击左侧“配置”后首先显示配置列表；单击选择配置，双击配置或点击“打开”后才进入样式编辑器。配置列表集中提供新建、导入、导出、重命名、删除和打开配置目录。

样式编辑器顶部显示当前 JSON 文件名、保存状态、保存和另存为，并提供返回配置列表。返回列表或离开编辑器时，未保存修改仍按“保存、放弃、取消”处理。

八个样式分类使用横向标签：页面、正文、标题、表格、代码块、图片、公式、编号。标签支持方向键、Home 和 End；窄内容区自动折行或缩减表单列数。界面配色使用全局主题变量。

- 页面：纸张/方向/尺寸与页边距分组，厘米单位明确，页面示意跟随尺寸及方向。示意图不代表真实 DOCX 渲染。
- 正文/标题：可分别输入中文字体和西文字体，常用字体通过建议列表快速选择，但不限制用户输入其他系统字体；文字样式和段落间距分组，字号与段距使用 pt，标题通过 H1–H6 切换。预览同步使用当前字体，并以中性纸张为底。
- 表格和代码块：均可分别配置中文字体和西文字体。
- 图片：除位置和尺寸外，可配置图注的中文字体、西文字体、字号和颜色；关闭图注时关联字段禁用。
- 表格、代码块、图片、编号：布尔设置使用统一开关，关联选项在不适用时禁用。
- 公式：Word OMML 与 LaTeX 文本选项使用明确名称。
- 恢复本项默认：仅恢复当前分类，标题分类仅恢复当前标题级别；由应用设置控制是否确认。

新建、另存为、重命名、删除和导入冲突继续使用小型确认弹窗；操作完成后，新建或导入的配置直接进入样式编辑器。

字段仍通过原有 updateGroup/updateStyle 和配置生命周期保存；本次仅重做编辑界面，没有变更 Python 配置协议。构建已通过，尚未完成实机视觉或功能验收。
