# 网页版迁移与验收

## 1. 产品范围

用户在 Windows、Linux 或其他设备的浏览器打开服务器首页，上传 Markdown、调整排版、提交转换、下载可编辑 DOCX。免费、免登录，无需用户安装 Python、Pandoc 或输入 API Key。

网页与 Agent 共用同一套 HTTP API。匿名会话自动生成，用于保护任务归属；不是长期注册 Key。网页凭证保存在 HttpOnly Cookie，不写入 JavaScript 的 localStorage。

## 2. 目录和维护边界

```text
server/
  api/                 HTTP 路由、请求处理和网页静态文件入口
    app.py
  web/                 独立网页工程，不依赖 desktop 的源码或 node_modules
    src/
      components/      从桌面版复制的 StyleEditor 与其 CSS
      config/          转换默认配置快照
      styles/          桌面基础样式快照与浏览器布局
      App.jsx          文档、排版配置和使用说明
      api.js           HTTP、上传清单和下载校验
    tests/             上传路径、限制和下载完整性测试
    dist/              本机构建产物，不提交 Git
  docs/                网页规划、产品文案、部署与验收
  scripts/             环境安装、前端构建、启动和服务配置生成
  deploy/              systemd 模板
  tests/               后端、安全、真实转换与网页资源测试
  app.py               旧入口兼容层
  jobs.py              任务调度
  runner.py            隔离执行
  store.py             持久化与限流
  settings.py          服务端配置
  data/                私有运行数据，不作为静态文件公开
```

服务层暂时保留原路径，避免无关迁移影响图片隔离子进程的模块挂载。API 和网页已经分目录，数据目录与静态资源分离。

## 3. 页面和文案

### 文档转换

- 标题：写作交给你，排版交给我们。
- 说明：上传 Markdown，保留表格、图片与公式，生成可编辑的 Word 文档。
- 输入：上传文件、选择文件夹、粘贴文本。拖放只接收文件；文件夹使用选择器。
- 格式：Markdown、PNG、JPEG；目录选择保留相对路径，远程图片不抓取。
- 设置：批量出错继续/停止、图片缺失继续/停止、跳转排版编辑。
- 按钮：开始转换、取消任务、下载 DOCX、删除云端结果。
- 状态：正在上传、排队中、转换中、正在取消、转换成功、部分完成、失败、取消、超时。
- 不伪造百分比：文件统计和阶段提示分别显示。
- 不自动触发大量下载：成功文件逐份手动下载，避免浏览器多文件下载拦截。

### 排版配置

沿用桌面版页面、正文、六级标题、表格、代码、图片与题注、公式、编号编辑器；引用等其他现有字段通过配置 JSON 导入保留。支持命名保存浏览器配置、切换、删除、导入、导出、分组恢复默认。

浏览器配置仅保存在本设备，不宣称跨设备同步。配置预览仅供参考，最终以 Word 显示为准。此版保留原默认编号策略，启用 stripExisting 时明确提醒年份等数字误删风险，未静默修改核心。

### 使用说明与隐私文案

明确文档会上传到服务器、输入在任务结束后清理、结果默认保留 24 小时、可主动删除。浏览器记住最近任务 ID，但不保存上传文件或正文；刷新后通过同一 Cookie 恢复最近任务。清除 Cookie、更换域名/IP/浏览器后不能保证恢复。

关闭网页不会取消任务。请求结果不确定时保留当前页的提交键和文件以供幂等重试；刷新后不会保存待上传字节，不能承诺恢复尚未确认的提交。

## 4. 接入与安全边界

- 浏览器请求使用相对 `/v1/...` 地址，同源 Cookie；不嵌入共享长期 Key，不允许任意自填远程 API 地址。
- 新增 GET /v1/sessions/current，只检查 Cookie 是否有效，不返回 token；上传前检查会话，以免覆盖已有任务归属。
- 上传使用 multipart 清单，目录路径、文件数量、字节和类型客户端预检；服务端继续执行完整验证，不信任浏览器判断。
- 网络提交结果不确定时使用原幂等键及原 FormData 重试；避免同一页面双击并发提交。
- 定时查询采用顺序请求；短时错误退避，连续失败后暂停并提示恢复。
- 文稿不作为 HTML 渲染；React 文本节点展示路径、告警和错误，减少脚本注入面。
- 下载检查字节数；HTTPS/localhost 下额外做 SHA-256。普通局域网 HTTP 的 Web Crypto 通常不可用，不能声称已验 SHA-256。
- 首页配置 CSP、禁止嵌入框架；静态挂载仅允许 dist/assets 和可选 dist/docs-assets，不公开源码、数据目录或任意服务器文件。
- Swagger 资源随前端构建保存到本地，不依赖外部 CDN。未构建时返回明确 503 信息。
- 限流、隔离、归属验证、超时、资源上限保留，不因网页接入放宽。
- 公网 TLS、入口防护、2 核 2G 实机压力测试仍需按 SECURITY.md 完成。

## 5. WSL 开发与构建

所有命令在 Linux 项目根目录执行：

```bash
bash server/scripts/install-node.sh
bash server/scripts/build-web.sh
conda activate md2docx
MD2DOCX_COOKIE_SECURE=0 bash server/scripts/run.sh --docs
```

固定 Linux x86_64 Node.js 24.22.2，官方包校验 SHA-256，安装在当前用户目录。npm 使用镜像和 package-lock 的完整性校验。前端构建后由 Python 提供静态资源，运行服务不需要另起 Vite 或 Node 进程。Node 不放进 Python 环境。

完整 bootstrap 会安装 Python 依赖、Pandoc、检查隔离、安装 Node、构建网页。Conda 自动识别 miniconda/miniconda3 或显式覆盖；创建环境默认使用清华 main 镜像，不改用户全局源配置。

网络覆盖参数：MD2DOCX_CONDA_CHANNEL、MD2DOCX_PIP_INDEX_URL、MD2DOCX_NPM_REGISTRY、MD2DOCX_NODE_DOWNLOAD_BASE。Node 镜像必须提供同一个官方归档，固定校验不变。不能以关闭 TLS 校验处理下载失败。

开发时可在 server/web 执行 npm run dev，但需要将实际 Vite 来源加入 MD2DOCX_ORIGINS；默认同源生产构建更适合虚拟机验收。

## 6. 用户现有 VMware 验收环境

当前记录：Ubuntu IP 192.168.220.101，Conda 位于 ~/miniconda。IP 可能随虚拟机 DHCP 改变，重启后重新确认。

先将本次 WSL 修改提交并推送到 GitHub，再在虚拟机执行以下步骤；未推送前 git pull 不会取得本次改动。

```bash
cd ~/md2docx
git pull --ff-only
bash server/scripts/install-node.sh
bash server/scripts/build-web.sh

VM_IP=192.168.220.101
MD2DOCX_SERVER_PYTHON="$HOME/miniconda/envs/md2docx/bin/python" \
MD2DOCX_HOST=0.0.0.0 \
MD2DOCX_COOKIE_SECURE=0 \
MD2DOCX_ORIGINS="http://${VM_IP}:8000,http://127.0.0.1:8000,http://localhost:8000" \
bash server/scripts/run.sh --docs
```

原服务先 Ctrl+C 停止；只启一个实例。Windows 浏览器访问 http://192.168.220.101:8000/，末尾是 /，不是 /docs。Windows 与 VMware NAT 已连通，无需再做端口映射。浏览器代理应绕过该私网 IP。

### 验收顺序

1. 首页加载、服务显示就绪，无外部 CDN 依赖。
2. 粘贴示例 → 转换 → 下载 → Word 检查中文、粗体、表格、可编辑公式、代码。
3. 关闭去除已有编号，确认标题年份保留；修改字体/页边距/纸张，确认结果生效。
4. 上传含 images/chart.png 的文件夹，检查图片；一次上传多份文档，逐份下载。
5. 导入桌面配置 JSON，检查八类编辑器、完整字段与导出；刷新后检查排版草稿、最近任务恢复。
6. 转换时取消；主动删除结果；Cookie 失效提示；输入超过限额提示。
7. 小窗口/手机宽度无横向内容截断；键盘可操作输入和样式页签。
8. 普通下载软件用户的安装包、桌面端本地转换保持原流程。
